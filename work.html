How we measure

Every engagement starts with a baseline.

  • Baseline firstDuring Unpack we record how the target process performs today: volume, time per task, error rate, response time. Without a baseline, "improvement" is a guess.
  • Success measures in the scopeThe signed scope names the measures that define success, so both sides know what "done" means.
  • Reported monthlyOn a Run & improve plan you receive a monthly report against the same measures.
  • Honest about limitsIf a process is not worth automating, or a tool cannot be integrated, we say so early.
